## 6) Orphan Article Recovery System

## Orphan Definition
A menopause article is orphaned if it has zero contextual inlinks from published, indexable posts/pages.

## Recovery Steps
1. Add one in-content link from the assigned pillar.
2. Add two in-content links from sibling cluster posts.
3. Add one reciprocal link from orphan post to its pillar.
4. Add one “related reading” link block in the orphan post.
5. Re-crawl and verify orphan status = cleared.

## Recovery SLA
- High-value orphan: fix within 3 business days.
- Standard orphan: fix within 7 business days.

## 7) Rank Math SEO Linking Optimization Rules

1. Ensure each menopause post includes:
   - 1+ pillar link,
   - 2–4 sibling links,
   - descriptive anchors.
2. Keep anchors natural and intent-aligned; avoid repetitive exact match.
3. Confirm title/meta reflect the same intent as linked siblings.
4. Improve heading hierarchy so linked sections are contextually relevant.
5. Use Rank Math analysis as guidance, not a reason to over-optimize.

## 8) WordPress Editor Instructions (Actionable)

1. Open article in WordPress editor.

4. Add 2–4 sibling links in context (not footer-only).
5. Add/update “Related menopause articles” block near end.
6. Save draft, run Rank Math checks, and confirm readability.
7. Publish update without changing slug/category/permalink.
