## Rank Math SEO optimization rules
1. Keep 3–8 internal links on standard posts; 8–20 on pillar pages.
2. Use mixed anchor types: exact-match (<30%), partial-match, branded, generic CTA.
3. Place at least one link above the first H2 and one in final section.
4. Ensure destination page target keyword aligns with surrounding sentence intent.
5. Re-run Rank Math link suggestions after updates and resolve orphan warnings first.

## Implementation priority order
1. Fix detected orphan articles (highest impact).
2. Build/confirm pillar-to-cluster links for each ecosystem.
3. Add sibling links inside each ecosystem cluster.
4. Add one contextual cross-cluster link per post.
5. Expand to category/page hubs and refresh quarterly.

## Reusable rules for all future articles
- Rule 1: On publish, assign one primary ecosystem and one cluster.
- Rule 2: Add 1 pillar link + 2 sibling links + 1 cross-cluster link before publishing.
- Rule 3: Reuse only existing URLs/slugs; never modify indexed paths.
- Rule 4: If no obvious siblings exist, link to category hub and nearest-intent pillar, then queue a new supporting article.
- Rule 5: Review internal links at 30 and 90 days after publication.
