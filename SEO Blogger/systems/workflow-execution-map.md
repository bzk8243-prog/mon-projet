# Workflow Execution Map — Lonage System

## Purpose

This document defines how all Lonage agents collaborate together inside the SEO ecosystem.

It establishes:
- execution order
- workflow logic
- task routing
- ecosystem governance
- publishing coordination

---

# Core Workflow Types

## 1. New Article Workflow

Purpose:
Create new SEO articles aligned with the Lonage ecosystem.

### Execution Order

1. SEO Audit Agent
   - analyze topic opportunity
   - validate ecosystem fit
   - detect cannibalization risks

2. Article Writer Agent
   - create article structure
   - build semantic depth
   - follow EEAT rules

3. Internal Linking Agent
   - connect article to pillars
   - connect sibling articles
   - reinforce ecosystem relationships

4. Rank Math Agent
   - optimize on-page SEO
   - improve titles/meta/headings
   - detect FAQ opportunities

5. Affiliate Optimization Agent
   - integrate monetization naturally
   - preserve trust and readability

6. WordPress Publisher Agent
   - validate publication readiness
   - verify categories/slugs/images
   - verify SEO completeness

# 2. Content Refresh Workflow

Purpose:
Improve existing Lonage content without damaging rankings.

### Execution Order

1. SEO Audit Agent

2. Content Refresh Agent
   - improve structure
   - improve semantic coverage
   - improve EEAT

3. Internal Linking Agent
   - improve authority flow
   - reduce orphan risks

4. Rank Math Agent
   - improve on-page SEO
   - improve FAQ/schema opportunities

5. WordPress Publisher Agent
   - validate refresh quality
   - preserve URL structure

Purpose:
Expand topical authority strategically.

- rename indexed URLs
- damage category structure
- create duplicate intent
- weaken ecosystem clarity
- generate low-value content
