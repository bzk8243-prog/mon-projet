# Menopause Article Audit Checklist (Lonage)

Use this checklist before any update is approved.

## A) Article Analysis
- [ ] Article belongs to menopause pillar/cluster map.
- [ ] Search intent still matches current URL.
- [ ] Content is not medically outdated.
- [ ] Weak or thin sections identified.

## B) Internal Linking
- [ ] Parent pillar link present.
- [ ] 2–5 relevant sibling links present.
- [ ] Cross-cluster link included where useful.
- [ ] No irrelevant or forced links.
- [ ] Anchor texts are natural and varied.

## C) Orphan Control
- [ ] Contextual inlink count checked.
- [ ] Orphan status resolved (if previously orphaned).
- [ ] Reciprocal link path back to pillar exists.

## D) Rank Math SEO
- [ ] Primary focus keyword aligned to intent.
- [ ] Title and meta description improved.
- [ ] Heading structure (H1/H2/H3) logical.
- [ ] Schema type appropriate.
- [ ] Image alt text optimized where relevant.

## E) Human Style Preservation
- [ ] Original writing voice preserved.
- [ ] No repetitive AI-style phrasing.
- [ ] No generic filler introductions/conclusions.
- [ ] Edits sound like a human expert wrote them.

## F) Publish QA
- [ ] WordPress formatting verified.
- [ ] Category/tags/slug reviewed.
- [ ] Updated date and change log recorded.
- [ ] Monitoring window set (14–30 days).
