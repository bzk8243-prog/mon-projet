# SOP: Menopause Content Refresh (Lonage)

## Purpose
Standardize how old menopause posts are refreshed while preserving brand voice and editorial quality.

## Trigger Conditions
Run refresh SOP when an article has one or more:
- declining impressions/clicks,
- poor average position,
- outdated guidance,
- weak internal linking,
- orphan risk.

## SOP Steps

1. **Collect baseline**
   - Save current title, meta, headings, and internal link map.
   - Record performance baseline.

2. **Intent lock**
   - Confirm exact query intent the URL should satisfy.
   - Remove off-intent sections.

3. **Section-level rewrite plan**
   - Mark sections as keep / update / replace.
   - Expand only where user value is clear.

4. **Internal linking upgrades**
   - Add/refresh parent pillar link.
   - Add 2–5 sibling cluster links.
   - Add one “next step” cross-link for journey progression.

5. **Human-style rewrite constraints**
   - Keep paragraph lengths mixed (avoid repetitive cadence).
   - Keep practical examples and natural transitions.
   - Avoid buzzword-heavy or overly polished AI tone.

6. **Rank Math improvements**
   - Re-align focus keyword.
   - Improve title/meta clarity.
   - Fix heading hierarchy and schema.

7. **Editorial review and publish**
   - Human editor signs off.
   - Publish in WordPress.
   - Log what changed and why.

8. **Post-publish validation**
   - Re-crawl internal links.
   - Confirm orphan status resolved.
   - Review performance at day 14 and day 30.
