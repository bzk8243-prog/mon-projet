# Lonage Future Publishing Workflow (SEO Structure First)

## Weekly cadence
- Monday: topic selection + cannibalization check
- Tuesday: outline + SEO brief + link targets pre-selected
- Wednesday: draft
- Thursday: edit + Rank Math optimization + internal linking
- Friday: publish + QA + index submission

## Pre-publish QA gates
1. Primary ecosystem assigned.
2. Parent pillar selected.
3. At least 4 internal links inserted.
4. URL slug validated (no change to existing indexed URLs).
5. Rank Math score reviewed (quality over score-gaming).

## Monthly maintenance sprint
- Week 1: orphan resolution
- Week 2: underlinked cluster reinforcement
- Week 3: CTR metadata refresh (title/meta intros)
- Week 4: menopause ecosystem review separately from non-menopause graph

## Menopause separation rule
- Menopause content planning runs in a dedicated queue.
- Non-menopause health/fitness planning runs in a separate queue.
- Crossovers require explicit editorial note to avoid intent dilution.
