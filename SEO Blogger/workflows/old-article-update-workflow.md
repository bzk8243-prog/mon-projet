# Lonage Workflow: Updating Old Menopause Articles

## Purpose
Refresh existing menopause content to recover rankings, improve internal linking, and maintain topical authority.

## Inputs
- Published article URL
- Assigned parent pillar
- Current Rank Math snapshot
- Performance data (impressions, clicks, CTR, average position)
- Internal inlink count

## Step-by-Step Workflow

1. **Triage & Prioritization**
   - Prioritize pages with ranking decay, outdated information, or weak internal links.
   - Classify update level: light refresh, moderate rewrite, full rebuild.

2. **Intent Revalidation**
   - Confirm primary search intent still matches the URL.
   - If intent drifted, reframe headings and intro before expanding content.

3. **Content Refresh**
   - Update definitions, examples, and practical menopause guidance.
   - Remove thin sections; expand missing subtopics tied to cluster intent.

4. **Internal Linking Upgrade**
   - Add/refresh parent pillar link in top section.
   - Add 2–5 relevant sibling cluster links.
   - Add reciprocal links from 1–3 related menopause articles.

5. **Rank Math Optimization**
   - Recheck focus keyword alignment.
   - Improve title/meta for clarity and click intent.
   - Validate heading structure, schema, image alt text, and readability.

6. **WordPress Publication Update**
   - Update modified date (when appropriate).
   - Verify slug, category, tags, and featured image relevance.
   - Publish update and log changes.

7. **Post-Update QA (7–21 days)**
   - Track movement in impressions, CTR, and positions.
   - Re-open if page remains underperforming or still weakly connected.

## Completion Criteria
- Parent pillar link present.
- Minimum sibling link quota met.
- No orphan status.
- Rank Math checks passed for key on-page elements.
- Update logged in maintenance tracker.
