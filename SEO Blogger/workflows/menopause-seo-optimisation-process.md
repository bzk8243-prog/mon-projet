# Menopause SEO Optimisation Process (Rank Math + Internal Linking)

## Goal
Improve on-page SEO structure of existing menopause articles without sacrificing readability or human tone.

## Process

1. **Keyword and intent alignment**
   - Set one primary keyword tied to the article’s cluster intent.
   - Add supporting secondary terms naturally.

2. **SERP-facing assets**
   - Optimize SEO title for clarity + user benefit.
   - Rewrite meta description with direct value proposition.

3. **Heading architecture**
   - Ensure H1 is singular and intent-aligned.
   - Use H2/H3 to reflect sub-intent progression.

4. **Internal link architecture**
   - Add parent pillar link.
   - Add sibling links based on semantic proximity.
   - Add at least one contextual inbound link source recommendation.

5. **Content quality enhancements**
   - Improve scannability (lists, concise sections, clear transitions).
   - Remove fluff and duplicated statements.
   - Preserve author style markers and tone.

6. **Rank Math validation pass**
   - Review recommendations and apply only user-value-positive fixes.
   - Avoid keyword stuffing to chase score.

7. **Final human QA gate**
   - Confirm “not AI-sounding” language quality.
   - Verify fact integrity and medical sensitivity.

## Done Criteria
- Parent pillar + sibling links implemented.
- Orphan risk addressed.
- Rank Math key checks complete.
- Human editor approved style quality.
