# Editorial Linking SOP (Lonage Full-Site Authority)

## Objective
Standardize editor actions for internal linking across all ecosystems.

## SOP Steps
1. Identify article ecosystem (Menopause, Healthy Aging, Fitness, Women’s Wellness, Recovery, Nutrition, Sleep, Gut Health, Mobility, Longevity).
2. Validate parent pillar mapping.
3. Add parent pillar link in first 40% of article.
4. Add 2–4 sibling links from same ecosystem cluster.
5. Add 1 cross-ecosystem bridge link if relevant.
6. Check for orphan recovery opportunity.
7. Review Rank Math internal linking/context warnings.
8. Approve only if content still sounds human and brand-consistent.

## Done Criteria
- No slug/category changes.
- Internal linking quota met.
- Orphan risk reduced.
- Rank Math internal linking checks satisfied.
