# WordPress Implementation Instructions (Global Authority System)

## Editor Workflow
1. Open the target post in WordPress.
2. Confirm ecosystem and parent pillar assignment.
3. Insert parent pillar link in upper half of article.
4. Insert 2–4 sibling links where user next-step is natural.
5. Insert 1 cross-category bridge link if context supports it.
6. Add/update “Related Articles” block near conclusion.
7. Run Rank Math checks and adjust headings/meta if needed.
8. Update post without changing slug/category/permalink.
9. Log links added in tracker.

## QA Before Publish
- Pillar link present.
- Sibling links present.
- Cross-ecosystem link validated.
- Anchor text is natural and varied.
- Rank Math warnings reviewed.
